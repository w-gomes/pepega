General:

Improve auto output names:
  After adding Optional output. The program picks a single default one for all Commands.
  If we want to chain commands, the one after the first command will overwrite the first output file.
  So, if we don't provide an output, we want to generate an output name based on the input command.
  That way the names won't clash.

  Add timestamp or UUID.


Improve temporary folders:
  Use a default temporary folder for commands like: merge and video.
  The command creates a folder where the program is invoked.
  Another way to solve this is: not create a temporary folder at all. Research a way to create a buffer and keep the file
  content in this buffer.
